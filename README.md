# WincyFu 个人网站

这是一个使用Next.js 14和Tailwind CSS构建的个人网站项目。

## 🚀 功能特点

- **响应式设计**：在各种设备上完美呈现
- **深色/浅色主题**：支持用户主题偏好切换
- **现代化组件**：使用最新的交互和动画效果
- **高性能**：使用Next.js的优化功能确保快速加载
- **作品集展示**：完整的项目作品展示系统
- **PDF作品集下载**：支持离线查看的PDF作品集
- **多语言支持**：中英文双语切换
- **项目详情弹窗**：支持图片和视频的混合展示
- **浏览计数功能**：实时统计项目浏览次数
- **水印保护**：作品图片自动添加水印保护

## 📦 技术栈

- **框架**: Next.js 14
- **样式**: Tailwind CSS
- **语言**: TypeScript
- **部署**: Vercel
- **组件架构**: 模块化设计，支持多页面独立样式管理

## 🛠️ 安装与使用

1. 克隆仓库
   ```bash
   git clone <仓库地址>
   ```

2. 安装依赖
   ```bash
   npm install
   ```

3. 启动开发服务器
   ```bash
   rm -rf .next
   npm run dev
   ```

4. 构建生产版本
   ```bash
   npm run build
   ```

## ⚠️ 重要维护提示

### 项目时间修改说明
作品集页面存在项目时间硬编码问题，修改时需要同时更新两个文件。详细说明请查看：
- 📄 [`PROJECT_TIME_MAINTENANCE.md`](./PROJECT_TIME_MAINTENANCE.md) - 完整维护文档
- 📄 [`src/app/portfolio-x7y9z/README.md`](./src/app/portfolio-x7y9z/README.md) - 作品集页面说明

### SpotlightCard组件架构说明
项目现在包含三个完全独立的SpotlightCard组件，避免样式冲突：
- **全局通用组件**: `src/components/UI/SpotlightCard.tsx` - 首页"AI辅助编码产品"使用
- **查看全部页面专用**: `src/app/all-designs/SpotlightCard.tsx` - 查看全部页面使用
- **作品集页面专用**: `src/app/portfolio-x7y9z/SpotlightCard.tsx` - 作品集页面使用

⚠️ **修改注意事项**：
- 修改SpotlightCard样式时需要明确修改的是哪个组件
- 全局组件的CSS文件padding设置会影响所有使用该组件的页面
- 建议优先使用页面级别的className而非CSS文件中的全局样式

## 如何回退到特定版本
如果需要回退到特定版本，请使用以下Git命令：

```bash
# 查看所有版本标签
git tag

# 回退到v1.3.5版本
git checkout v1.3.5
```

如果您使用的是版本控制但未设置标签，可以使用提交记录：

```bash
# 查看提交历史
git log --oneline

# 回退到特定提交
git checkout <commit-hash>
```

## 技术栈

- **前端框架**: Next.js 14
- **编程语言**: TypeScript
- **样式框架**: Tailwind CSS
- **动画库**: Framer Motion
- **状态管理**: React Context API
- **组件架构**: 模块化独立组件设计
- **部署平台**: Vercel
- **版本控制**: Git
- **包管理**: npm

## 本地开发

1. 克隆项目
```bash
git clone <repository-url>
```

2. 安装依赖
```bash
npm install
```

3. 配置PDF作品集（可选）
```bash
# 创建PDF文件目录
mkdir -p public/portfolio

# 将PDF作品集文件放入目录
# 文件名应为：WincyFu-Portfolio.pdf
```

4. 启动开发服务器
```bash
rm -rf .next
npm run dev
```

5. 在浏览器打开 [http://localhost:3001](http://localhost:3001)

## 构建生产版本
```bash
npm run build
```

## 部署
该项目配置为使用Vercel自动部署。将代码推送到主分支后，Vercel将自动构建和部署最新版本。
