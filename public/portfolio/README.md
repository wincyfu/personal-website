# 作品集PDF文件说明

## 文件位置
请将您的作品集PDF文件放置在此目录下，文件名为：`WincyFu-Portfolio.pdf`

## 文件要求
- 文件格式：PDF
- 文件名：WincyFu-Portfolio.pdf（必须与代码中的文件名完全一致）
- 建议文件大小：不超过20MB，确保下载速度
- 文件内容：完整的个人作品集

## 使用说明
1. 将作品集PDF文件重命名为 `WincyFu-Portfolio.pdf`
2. 放置在 `public/portfolio/` 目录下
3. 用户在"全部设计作品"页面点击"下载作品集"按钮即可下载

## 文件路径
```
public/
  └── portfolio/
      ├── README.md (本说明文件)
      └── WincyFu-Portfolio.pdf (您的作品集PDF文件)
```

## 注意事项
- 确保PDF文件可以正常打开和阅读
- 建议在上传前压缩文件大小以提升下载体验
- 定期更新作品集内容以保持最新状态
